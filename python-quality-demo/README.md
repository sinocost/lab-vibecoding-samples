# Python Quality Demo

用于学习和实践 Python 工程质量保障体系的最小示例项目。

## 学习目标

逐步建立以下自动化质量检查：

1. **Lint / Format**：Ruff
2. **Static Type Checking**：mypy
3. **Syntax Compilation**：compileall
4. **Automated Tests**：pytest
5. **Continuous Integration**：GitHub Actions

## 技术栈

- Python 3.12
- uv
- FastAPI
- Ruff
- mypy
- pytest
- GitHub Actions

## 当前阶段

项目初始化。后续按教学步骤逐项添加配置、应用代码、测试和 CI 工作流。

## 本地开发

克隆仓库后切换到实验分支：

```bash
git clone git@github.com:sinocost/lab-vibecoding-samples.git
cd lab-vibecoding-samples
git switch lab/python-quality-demo
cd python-quality-demo
```
